——————————————————————————

Colonnes du tableau principal :
  Référence | Code à barre | Désignation (tri ↑↓) | Catalogue | Famille | S.Famille | En stock |
  Pu achat.HT | T1.HT | T1.TTC | Dernière ACHAT (date, valeur achat, Nbr jours) |
  Dernière VENTE (date, valeur vente, Nbr jours)

Section inférieure — Distribution par dépôt :
  Colonnes : Nom dépôt | Quantité | Mouvement d'article | Maj Stock
  Dépôts listés : Dépôt principale, véhicules chauffeurs (ex: mokhtar 206TU7140, HICHEM 238TU1019, FOUED 243TU3251)

Boutons d'action (haut droite) :
  [⚙ Colonnes] [+ Ajouter] [✏ Modifier] [🗑 Supprimer] [≡ Tri] [↺ Actualiser] [🖨 Imprimer] [🔽 Filtrer] [Excel]

Fiche article (formulaire de création/modification) :
  Section Identification :
    - Référence (obligatoire), Référence origine, Code à barre
    - Unité de stockage & Unité d'entrée (ex: Litre, Pièce) + coefficient de conversion
    - Désignation (français) + bouton traduction arabe [AR]
    - Caractéristiques : champ texte libre pour spécifications techniques
  Section Classification :
    - Catalogue, Famille, Sous-famille, Marque, Sous-catégorie (+ création rapide [+])
  Section Tarification :
    - Bloc Achat : PU achat HT, Remise, Fodec achat, PU achat TTC, Taux TVA
    - Bloc Tarif Vente : Prix unitaire HT, Prix unitaire TTC, Marge %, Fodec Vente, Remise, Taux TVA
    - Indicateurs : pu Inv (Prix inventaire), dpa (Dernier Prix Achat), pmp (Prix Moyen Pondéré)
    - Boutons : [MAJ] [PMP] [VENTE]
  Section Statuts :
    - Type d'article : [Produit fini] [P.semi-fini] [M.première]
    - [Vendable] [Achetable] [Archiver]
  Boutons de contrôle :
    [💾 Enregistrer] [+ Nouveau] [✕ Fermer]

14. SYSTEME DE REPORTING GLOBAL
=========================================================
Chaque module dispose d'une section Rapports avec :

A. Rapports Stock :
  - Etat de stock (valorisation HT/TTC à une date)
  - Rotation de stock (articles à rotation lente)
  - Historique des mouvements (par dépôt, article, utilisateur)
  - Export Excel de tous les rapports

B. Rapports Vente & Performance :
  - CA par Client / par Commercial (graphiques)
  - Top articles générant le plus de marge
  - État des créances clients (factures non payées, ancienneté)
  - Etat des soldes clients
  - Statistiques de vente / par magasin

C. Rapports Achat :
  - Volume achat par Fournisseur
  - Analyse des dépenses d'approvisionnement
  - Rapport fournisseurs

D. Rapports Trésorerie :
  - Flux de trésorerie (Cash-flow) : Entrées vs Sorties mensuelles
  - Balance globale de trésorerie
  - Extrait de compte bancaire

E. Rapports Charges :
  - Analyse mensuelle par catégorie de charge
  - Tableau annuel (Jan → Déc par type de dépense)
  - Filtre par année

F. Rapports GPAO/Production :
  - Calcul du Besoin Net (CBN)
  - Ordonnancement des ordres de fabrication
  - Planification visuelle (calendrier Gantt)
