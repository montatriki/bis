1. CONNEXION (Login)
================================================================================
URL : http://41.226.17.73:3000/login

CHAMPS DU FORMULAIRE
  - Login    : champ texte  | id="login"    | saisie du nom d'utilisateur
  - DB       : champ texte  | id="db"       | auto-rempli avec "bis" après saisie du login (~800ms)
  - Password : champ texte  | id="password" | mot de passe

COMPORTEMENT
  - À la saisie du login, le champ DB se remplit automatiquement ("bis") via un mécanisme
    de correspondance login→base de données
  - Délai nécessaire : attendre ~1 seconde après saisie du login avant de remplir le mot de passe
  - Si le champ DB ne se remplit pas automatiquement, injecter la valeur via React nativeInputValueSetter

BOUTON
  - [SE CONNECTER] — soumet le formulaire

FLUX D'AUTHENTIFICATION
  1. POST /users/generateToken  → obtention d'un token JWT
  2. POST /users/login          → authentification avec le token
  3. Token stocké en mémoire React (perdu si la page est rechargée)
  4. Toutes les requêtes API suivantes incluent le JWT dans le corps de la requête
